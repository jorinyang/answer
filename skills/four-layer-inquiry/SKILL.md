# 四层追问

四个问题，一层一层问：

```
这是什么   →   我怎么知道   →   为什么重要   →   该怎么做
（本体）        （认识）          （价值）          （方法）
```

每一层都是下一层的基础。上一层没问清，不许进下一层——因为方法不管用，多半不是方法不好，是前一层就没站住。

大多数人遇到问题，第一句就是「怎么办」。这个技能的作用，就是在「怎么办」之前先拦一下。

---

## 什么时候用

- 一个判断迟迟下不去手：要不要接、要不要买、要不要换、要不要现在做
- 一件事讨论了很久没有结论（八成是定义没统一，大家在聊不同的东西）
- 别人给了一个结论，你想验证它靠不靠得住
- 手上已有一堆方案，但说不清为什么是这些方案

## 什么时候不用

- 单一事实查询（几点、多少钱、文件在哪）——直接查
- 已经有定论，只需要执行——直接做
- 用户明确要的是产出物（方案、PPT、代码），不是想清楚——那是执行类工作，别拿追问拖时间

---

## 只问不答

这个技能的主要动作是**问**，不是给答案。

三条纪律：

1. **能查到的先查**，查不到再问人。拿文件、数据、历史对话能回答的，不要拿去问用户。
2. **一层一次只问 1–3 个问题**，等对方答完再往下。一次抛十个问题，对方只会挑好答的答。
3. **可以给推荐，但要标出来是推荐**。你的判断不能替对方下结论。

---

## 第一层：本体 —— 这东西到底是什么

先统一「我们在聊什么」。很多争论没有结果，不是观点不同，是连讨论对象都没统一。

要问的：

- 你说的「X」，具体指什么？举一个具体例子。
- 去掉 Y，它还是 X 吗？加上 Z，它还是 X 吗？
- 它和 W 的界线在哪？最容易混的是哪个？
- 用一句话定义它。这句话要能被反驳——不能被反驳的定义等于没说。

**合格**：一句话定义 + 三个例子（是 / 不是 / 边界）。

**不合格**：列一堆属性；用同义词解释（「就是把 A 做成 B」）；「视情况而定」。

> 文章里的例子：「自律」不是「每天早起、健身、读书」，而是「为长期目标主动克制当下的冲动」。定义一换，有人早起只是生物钟，不叫自律；有人熬夜写方案，反而是自律。定义决定后面所有判断。

---

## 第二层：认识 —— 我是怎么知道的

大部分认知是「听说的」「感觉的」「大家都这么说」。这一层就是查它们的出处。

要问的：

- 这个说法最初从哪来？谁说的？
- 他是第一手经历，还是转述？他有没有立场？
- 有反例吗？有没有人不同意，理由是什么？
- 如果这条信息不成立，你的判断会变吗？（会变，才说明它是关键依据）

**合格**：每条关键断言都有来源 + 类型（一手 / 二手 / 推测）+ 可信度（高 / 中 / 低）。

**不合格**：「大家都这么说」「行业惯例」「客户一般都需要」；只有结论没有出处。

> 文章里的例子：「每天喝 8 杯水才健康」——8 杯是多大的杯？对谁？哪个研究？样本多大？有没有利益相关方？问到这里，很多「常识」自己就塌了。
>
> 职场的例子：领导说「这个方案不行」。问「哪里不行」只停在本体层；问「你基于什么数据或经验，有没有成功案例」才是认识层——问完常常发现对方的判断站不住。

---

## 第三层：价值 —— 它为什么重要、有多重要

这一层决定要不要投入。跳过它，人就会去考证、搞副业、学英语，只因为「别人说重要」。

要问的：

- 这件事对你意味着什么？能帮你解决哪一个具体问题？
- 不做会怎样？三个月后它还重要吗？
- 如果只能做一件，是这件吗？
- 这是你自己的目标，还是别人的焦虑传给了你？

**合格**：能排出「现在必做 / 可以排后 / 不该做」三档，并说出不做的代价。

**不合格**：「很重要」「能提升效率」——没有对象、没有时间尺度、没有代价。

> 文章里的例子：学英语的价值不在「英语重要」，在「你是要出国、升职，还是纯粹兴趣」。工作和生活都用不到，价值就很低。

---

## 第四层：方法 —— 该怎么做

到这一层才谈动作。它是前三层的结论，不是拍脑袋的清单。

要问的：

- 基于前三层的结论，最小的一步是什么？
- 这条路依赖什么前提？前提不成立会断在哪？
- 什么信号出现，说明走错了、该停？
- 换做法、换赛道的成本是多少？

**合格**：最小动作 + 依赖的前提 + 停止信号。

**不合格**：一上来就是全景路线图；只列步骤，不写为什么这么走。

> 文章里的例子：内卷的解法不是「更努力」。定义清楚（存量博弈中为相对优势付出的无效努力）之后，才会看到两条路：换赛道去增量市场，或提升不可替代性跳出循环。

---

## 逐级规则

1. **顺序不可跳**：上一层没结论，不进下一层。卡住就直接说「这一层还没站住，我们先停在这」。
2. **可以回退，但只回退一层**：价值层判「不值得」，回本体层缩范围；认识层发现证据不足，把结论降级为「假设」再往下走。
3. **同一层追问不超过 3 轮**。3 轮还问不出，说明信息不够，收口成「待确认」，不要硬凑一个答案。
4. **全程不替对方下结论**。

## 反模式

| 反模式 | 为什么错 |
|---|---|
| 第一句就问「怎么办」 | 前三层没定，方法再多也是乱试 |
| 把定义写成同义词 | 换了个说法，问题没动 |
| 用「大家都这么说」当依据 | 来源不明 = 没有依据 |
| 把「重要」当价值判断 | 没有对象、时间、代价，等于没说 |
| 一上手就给全景路线图 | 路线图成本最高、最不可逆 |
| 追问变成审讯 | 每层 1–3 问，答完就往下走 |

---

## 一句话

世界很复杂，但判断可以简单：**先定名，再举证，再定值，最后定策。**
